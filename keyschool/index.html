Learning path

  1. FOUNDATIONS — listen to the keyboard
  2. GUIDE — see and name each key
  3. NOTES — test note recall
  4. INTERVALS — hear distances
  5. CHORDS — hear and build shapes

Quick start

BETA: press PLAY to listen, pass the guided test, then practise. Use SEQ for the next module, PRESET for notation and HOME to reset.

About the M-VAVE FM-1

The FM-1 is a compact battery-powered synthesizer and MIDI controller with a 240 × 240 display, velocity-sensitive keys, four performance knobs, USB, Bluetooth MIDI and a TRS MIDI connection.

KEYSCHOOL uses the display and keyboard as a beginner-friendly music classroom: the emulator runs the same application logic as the firmware intended for the hardware.

Install on the FM-1

  1. Download the current beta .fwsc package below.
  2. Open the FM-1 web installer in Chrome or Edge.
  3. Connect the FM-1 by USB, choose the downloaded file and follow the installer prompts.
  4. Keep the original M-VAVE firmware available for recovery and remember that KEYSCHOOL hardware support is still beta.

Technology & references

What powers it

  • C firmware: the same lesson and audio code targets FM-1 hardware and the host emulator.
  • WebAssembly: the browser simulator runs the firmware without an FM-1.
  • fm1-base: platform layer, browser emulator, MIDI, packaging and installer tooling.
  • JieLi AC79 SDK: the vendor SDK used by the hardware build through fm1-base.
  • GitHub Actions: reproducible host tests and `.fwsc` release builds.
